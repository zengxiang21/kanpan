fix: 手机端宽表加横滚提示，改善龙头分层等页面的可滑动可发现性

用户反馈「龙头分层下面的没法滑动，有遮挡」。

排查：HTML 结构与 CSS 规则都是对的（.panel > .tbl，.panel 有
overflow-x:auto，.tbl 有 min-width:max-content），横滚能力本身存在。
问题在于可发现性——面板能左右拖，但视觉上没有任何线索，
右侧超出的内容看起来就像被屏幕裁掉，于是被描述成「没法滑动 + 有遮挡」。

修复：用 :has() 给含表格的面板加一行提示「← 左右滑动查看全部列」，
纯 CSS，不动任何 JSX（全站有 51 处 table.tbl，逐个包 wrapper 风险高）。
::after 是 block，位于表格下方一行，不参与横滚内容。

同时补充说明一个已知限制：
.panel 的 overflow-x:auto 会把 overflow-y 也按规范计算为 auto，
.panel 因此成为滚动容器，.tbl th 的 sticky 包含块是 .panel 而非窗口。
因 .panel 无 max-height、高度等于内容，垂直方向不溢出，
所以手机端表格吸顶实际不生效（表头随表格一起滚出视口）；
桌面端 .panel 没有 overflow-x，吸顶正常。
已把该说明写进 CSS 注释。若用户实际遇到的是「表头消失、列名对不上」，
需要把横滚下沉到表格 wrapper（要改 51 处 JSX），届时再做。
