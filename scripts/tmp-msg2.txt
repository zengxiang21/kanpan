fix: 手机端菜单栏高度改为变量同源，修表格表头被压住

用户反馈「美股宏观数据日历和美股大公司财报文案在手机上会遮挡」。

根因：菜单栏高度、内容顶部留白、表格吸顶表头这三处各写死，互不同步：
- 菜单栏高度靠内容撑（brand 36px / menu 43.6px / foot 25.2px 取最高）+ border ≈ 44.6px
- 表头 sticky top 写死 46px
- 内容 padding-top 写死 58px

Microsoft YaHei 行高偏大（约 1.3）时栏高会到 45.9px，与表头的 46px
只剩 0.1px 余量，任何字体渲染差异就让表头被菜单栏压住——宏观日历和
财报日历都是 5 列宽表，正是最依赖吸顶表头的两处，所以最先暴露。

修复：引入 --bar-h 变量（固定 48px），三处同源：
- .sidebar { height: var(--bar-h) }  固定栏高，不再靠内容撑
- .content { padding: calc(var(--bar-h) + 10px) 10px 24px }
- .tbl th { top: var(--bar-h) !important }

并加测试反向断言：表头 top 与内容 padding-top 不得再写死 px，
否则失步后会重现压住/留缝。

已知限制（未改，需说明）：
.panel { overflow-x: auto } 会让 overflow-y 被规范计算为 auto，
.panel 因此成为滚动容器，sticky 表头的包含块变成 .panel 而非窗口。
由于 .panel 无 max-height、高度等于内容，垂直方向不溢出，
所以手机端表格实际不吸顶（表头随表格一起滚出视口）。
桌面端 .panel 没有 overflow-x，吸顶仍然正常。
若要让手机端也吸顶，需把横滚下沉到表格的 wrapper 元素（要改多处 JSX），
暂未做——先确认这是否是用户实际遇到的问题。
