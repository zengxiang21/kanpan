# 短线看盘工作台（工作名，GitHub 建仓时定名）

> A 股超短线（打板 / 低吸 / 半路）一体化看盘 Web。盘前定方向、盘中抓信号、盘后做复盘，全部基于免费公开数据，可零成本部署。

## 定位与差异化

开源圈现状（2026-10 调研，40+ 仓库）：涨停池 / 连板天梯 / 题材轮动 / AI 复盘已有很多（vibe-astock 856⭐ 为最强对标），
但以下四块是空白，正是本项目重点：

1. **各平台热榜聚合**（东财人气榜 / 雪球 / 百度热搜 / 淘股吧）→ 量化个股"辨识度"
2. **龙头回调 → 明日回流预期扫描**（断板低吸 / 龙头二波）→ 开源圈无人做成功能
3. **开仓环境评分卡**（根据大盘与情绪决定今天能不能出手）→ 只有零星近似
4. **隔夜外围映射 + 舆论热点雷达**（美股涨的方向、新闻炒作的方向自动标注到 A 股概念）→ 空白

## 功能模块

### 一、盘前 · 今日预期页（9:00–9:25）

- **隔夜外围**：美股三大指数 + 纳指明星股/中概股涨跌 + 美股强势板块，
  通过"美股标的 → A 股概念"映射表自动标注隔夜催化方向（如 NVDA 大涨 → 算力/CPO/液冷）
- **舆论热点雷达**：财联社电报 / 东财快讯 / 新浪财经 7×24 词频统计（题材词典映射到东财概念板块），
  结合各平台热榜，输出"最近 3 天舆论在炒的方向"及热度趋势
- **昨日涨停溢价**：昨日涨停股今日（竞价/收盘）平均溢价、翻红率、晋级率（1进2 / 2进3 / 3进4）——情绪先行指标
- **连板天梯**：各高度梯队及断层情况
- **集合竞价雷达**（9:20–9:25）：高开 2%~7% + 竞价量比放大 + 热点题材 + 非一字 → 竞价抢筹候选；
  弱转强识别（昨日烂板今日高开放量）；竞价评分 Top 榜
- **开仓环境评分卡**（0–100）：大盘趋势 / 量能 / 赚钱效应（涨停数、炸板率）/ 连板高度 / 昨日涨停溢价
  → 输出档位：重仓出击 ≥75 / 轻仓试错 50–75 / 只看低吸 30–50 / 空仓观望 <30

### 二、盘中 · 看盘页（9:30–15:00）

- **情绪仪表盘**：涨停/跌停数、炸板率、涨跌家数比、两市成交额（vs 昨日同时段）
- **板块题材轮动**：概念涨幅榜 + 板块内涨停家数 + 主力净流入 + 轮动方向箭头
- **涨停监控**：涨停池实时刷新、封单强度（封成比/封流比）、炸板即时预警
- **形态选股扫描器**（核心）：
  - 放量突破：量比 ≥1.8 + 突破 20/60 日新高 + 涨幅 3%~7%（可上车位置）
  - 缩量回踩：10 日内强势股回踩 MA5/MA10 ±2% + 量能缩至 5 日均量 0.5~0.8 倍
  - 均线多头、首板/连板池等模板，参数全部可调
  - 过滤器：剔除 ST / 次新 / 北交所，流通市值区间可调
- **买点信号**：
  - 打板点：涨幅 >9% + 封单快速增长 + 板块联动 → 打板候选
  - 半路点：站上分时均价线 + 放量突破早盘平台
  - 低吸点：强势股回踩分时均价线 / 5 日线缩量企稳
- **龙头回流预期扫描**：题材龙头断板 1~3 天 + 缩量回踩未破 5/10 日线 + 板块仍有活口
  → 明日回流候选池（次日竞价高开 + 早盘放量 = 回流确认）
- **异动提醒**：急拉 / 跳水 / 放量 / 触均线 / 涨停 / 炸板 → 浏览器通知
- **自选股盯盘**：分组自选 + 实时行情（3~5 秒）+ 分时/K 线

### 三、盘后 · 复盘页（15:00 后）

- **自动复盘报告**：当日涨停原因归类、题材梯队总结、明日预案（接力候选 / 低吸候选）
- **龙虎榜**：席位明细 + 游资席位库（知名游资动向跟踪）
- **龙虎榜游资库 + 大宗交易**
- **交易日志**：手动记录买卖点 + 胜率 / 盈亏比 / 连续回撤统计（超短线自检刚需）

### 四、超短线知识库

情绪周期六阶段（冰点→启动→发酵→高潮→分歧→退潮）量化定义与对应打法、
竞价战法（抢筹 / 弱转强 / 一字开板）、买点三式图解、卖点纪律（断板 / 冲高回落 / 尾盘跳水）、
仓位管理、术语表；每条知识点可跳转到对应功能页。

## 技术架构

```
前端   React + Vite + TypeScript + KLineChart(K线) + ECharts(分时/情绪/热力图)
后端   Python FastAPI + APScheduler + SSE 推送
数据   akshare（涨停池/板块/龙虎榜/热榜/快讯，全部免费无 token）
       东财全市场快照接口（一次拉全部 A 股，3~5 秒轮询）
       新浪/腾讯行情接口（指数、美股、港股）
计算   pandas：实时量比（当前成交量 vs 同时段5日均量）、均线、形态判定
存储   SQLite（日线历史本地化 + 信号与交易日志）
词典   美股→A股概念映射表、题材词典、游资席位库（JSON 配置，人工维护可迭代）
```

### 部署：双模式（全免费）

- **本地实时模式**：`python run.py` 起后端 + 前端 build，秒级轮询、竞价雷达、买点信号全功能
- **GitHub Pages 模式**：GitHub Actions 每个交易日 15:10（北京时间）跑收盘复盘 + 形态扫描，
  结果写 JSON 发布到 Pages，静态站直接可看——无需任何服务器（盘中秒级功能仅本地模式可用）

### 已知限制（免费数据边界）

- Level2 逐笔/十档：付费，不做；3~5 秒快照对短线看盘够用
- 涨停原因归类：无稳定免费源，方案 = 词库规则自动打标 + 人工补录
- 北向资金实时：2024-08 起停止盘中披露，只做盘后汇总
- 公开接口均为爬取性质，存在限频与变动风险，代码层做兜底与缓存
